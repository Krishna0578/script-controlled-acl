# Project Planning Phase

Project Title: Script-Controlled ACL

## Project Objective

To implement a secure and role-based access control system in ServiceNow using ACL rules and scripts.

## Project Tasks

1. Create the Institution Details table.
2. Create required users and roles.
3. Configure Create, Read, Write and Delete ACLs.
4. Assign appropriate roles to users.
5. Implement script-based access control.
6. Test access for different user roles.
7. Document the project results.
8. Prepare the project demonstration.

## Technologies Used

- ServiceNow Platform
- Access Control Lists (ACLs)
- ServiceNow Scripting

## Expected Outcome

The system should allow or deny access to Institution Details records according to the user's role and the configured ACL conditions.
